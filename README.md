# AIO Store Flipbook

Website katalog digital seperti buku untuk dibagikan melalui WhatsApp, gratis melalui GitHub Pages. Tambah JPEG di folder `flyers` dan halaman katalog akan terbuat otomatis saat build Jekyll.

**PANDUAN:** Baca `PANDUAN-SETUP.md`.

> Jangan hapus `_config.yml` atau membuat `.nojekyll`. Kedua hal tersebut akan mematikan pembacaan flyer otomatis.
